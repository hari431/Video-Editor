CASE EXPRESSIONS
================

CASE expressions implement conditional logic inside SQL queries.

SIMPLE AND SEARCHED CASE
------------------------
A simple CASE compares one expression to several values. A searched CASE evaluates boolean conditions.

EXAMPLE
-------
SELECT policy_number,
       CASE
         WHEN premium >= 10000 THEN 'HIGH'
         WHEN premium >= 5000 THEN 'MEDIUM'
         ELSE 'LOW'
       END AS premium_band
FROM policies;

USES
----
CASE is useful for classification, conditional aggregation, display labels, and business-rule mapping.

COMMON MISTAKES
---------------
Overlapping conditions, forgetting ELSE behavior, and putting large application decision trees into SQL when they belong in a domain service.

KEY TAKEAWAYS
-------------
CASE is powerful for concise classification, but complex business rules should remain maintainable and testable.
