AGGREGATE FUNCTIONS
===================

Aggregate functions summarize multiple rows into values such as counts, sums, averages, minimums and maximums.

EXAMPLES
--------
COUNT counts rows or non-null expressions depending on the expression used. SUM, AVG, MIN and MAX summarize values.

EXAMPLE
-------
SELECT policy_status, COUNT(*) AS policy_count
FROM policies
GROUP BY policy_status;

NULL BEHAVIOR
-------------
Many aggregates ignore NULL values. This can make AVG or SUM differ from an intuitive row count, so NULL semantics must be considered.

COMMON MISTAKES
---------------
Mixing aggregated and non-aggregated columns incorrectly, counting a nullable column when COUNT(*) is intended, and ignoring duplicate rows introduced by joins.

KEY TAKEAWAYS
-------------
Aggregation is straightforward only when row cardinality and NULL behavior are understood.
