SQL BASICS
==========

SQL is a declarative language for working with relational data. Instead of describing every low-level operation, a query expresses the result that is wanted and the database optimizer chooses an execution strategy.

RELATIONAL MODEL
----------------
Tables contain rows and columns. Keys identify rows or relationships, while constraints express data rules. SQL dialects differ, so production code should account for the database engine in use.

BASIC QUERY
-----------
SELECT chooses columns, FROM identifies a source, WHERE filters rows, ORDER BY sorts the result, and LIMIT/FETCH syntax can restrict output depending on the database.

EXAMPLE
-------
SELECT policy_number, status
FROM policies
WHERE status = 'ACTIVE'
ORDER BY policy_number;

COMMON MISTAKES
---------------
Using SELECT * in stable application interfaces, filtering after fetching large datasets, and assuming all SQL syntax behaves identically across databases are common problems.

KEY TAKEAWAYS
-------------
SQL is declarative: express the required result clearly, then understand how the database will execute it.
