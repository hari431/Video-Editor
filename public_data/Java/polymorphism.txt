POLYMORPHISM
============

Polymorphism lets code work with a common type while the runtime object determines the implementation of an overridden method.

RUNTIME DISPATCH
----------------
If a variable has an interface or superclass type, invoking an overridden instance method normally uses the runtime object's implementation.

EXAMPLE
-------
List<String> values = new ArrayList<>();
values.add("A");
process(values);

WHY IT MATTERS
--------------
Polymorphism reduces hard-coded dependencies. A service can depend on an interface while different implementations provide production, test, or specialized behavior.

COMMON MISTAKES
---------------
Confusing overloading with overriding, relying on implementation-specific behavior through a broad type, and designing interfaces that are too large reduce the value of polymorphism.

KEY TAKEAWAYS
-------------
Polymorphism is a key mechanism for substitutable implementations and loosely coupled designs.
