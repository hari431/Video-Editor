CONCURRENCY AND SYNCHRONIZATION
===============================

Synchronization establishes safe coordination when multiple threads access shared mutable state.

VISIBILITY AND ATOMICITY
------------------------
A thread may need to see another thread's writes, and an operation may need to occur as one indivisible unit. Synchronization mechanisms address these concerns in different ways.

TOOLS
-----
synchronized, volatile, atomic classes, locks and concurrent collections serve different purposes. Choose the simplest mechanism that satisfies the required guarantees.

EXAMPLE
-------
private final AtomicInteger count = new AtomicInteger();
count.incrementAndGet();

COMMON MISTAKES
---------------
Using volatile as a replacement for all synchronization, holding locks across slow operations, and creating lock-order cycles that can deadlock.

KEY TAKEAWAYS
-------------
Concurrency correctness depends on visibility, atomicity and ordering guarantees. Choose synchronization primitives deliberately.
