JAVA BASICS
===========

Java is a general-purpose, strongly typed language used for backend services, enterprise systems, Android-era applications, tools, and many large-scale platforms.

CORE IDEA
---------
A Java program is compiled into bytecode and normally executed by the Java Virtual Machine (JVM). This gives Java a useful separation between source code and the runtime environment. The language emphasizes readability, object-oriented design, strong typing, and a mature standard library.

EXAMPLE
-------
A small program can be thought of as:
class Hello {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
The main method is an entry point for a normal command-line Java application.

WHY IT MATTERS
--------------
Understanding the basic compilation/runtime model makes later topics such as classes, exceptions, collections, streams, concurrency, and JVM memory much easier to reason about.

COMMON MISTAKES
---------------
Confusing the JDK with the JVM, treating Java as purely object-oriented without understanding primitives, and ignoring compile-time type checking are common beginner mistakes.

KEY TAKEAWAYS
-------------
Java source is compiled to bytecode and executed by a JVM; strong typing and a large standard library are central to the platform.
