COLLECTIONS FRAMEWORK
=====================

The Java Collections Framework provides common abstractions and implementations for groups of objects, including List, Set, Map, Queue and related types.

LIST, SET, MAP
--------------
List preserves positional ordering and allows duplicates. Set focuses on uniqueness. Map associates keys with values. Choose based on the operation and semantic requirement.

IMPLEMENTATION CHOICE
---------------------
ArrayList is commonly efficient for indexed access and append-oriented workloads. HashSet and HashMap provide hash-based lookup under suitable hash distribution. Linked structures have different trade-offs and should not be chosen by folklore.

EXAMPLE
-------
Map<String, Integer> counts = new HashMap<>();
counts.merge("JAVA", 1, Integer::sum);

COMMON MISTAKES
---------------
Assuming all collections have the same performance, mutating keys after insertion into a hash map, and using a list when uniqueness is the real requirement.

KEY TAKEAWAYS
-------------
Select collections by semantics first and performance characteristics second; understand equality and hashing before using hash-based collections.
