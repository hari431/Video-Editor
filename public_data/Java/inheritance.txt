INHERITANCE
===========

Inheritance allows one class to extend another class. It can model a genuine is-a relationship, but it should not be used merely to reuse a few methods.

HOW IT WORKS
------------
A subclass inherits accessible behavior and can add or override behavior. Java supports single class inheritance, while multiple behavioral contracts can be expressed with interfaces.

EXAMPLE
-------
class Vehicle { void start() {} }
class Car extends Vehicle {
    @Override void start() { /* car-specific behavior */ }
}

DESIGN GUIDANCE
---------------
Inheritance creates coupling between parent and child. Changes in a base class can affect many subclasses, so composition is often preferable when the relationship is not truly hierarchical.

COMMON MISTAKES
---------------
Deep inheritance trees, overriding methods without preserving expected contracts, and using inheritance only for code reuse make systems harder to evolve.

KEY TAKEAWAYS
-------------
Inheritance is best used for stable behavioral hierarchies with a meaningful is-a relationship; otherwise consider composition.
