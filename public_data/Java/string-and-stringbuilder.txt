STRING AND STRINGBUILDER
========================

String is immutable in Java. StringBuilder provides a mutable sequence useful for repeated string construction.

IMMUTABILITY
------------
Once a String object is created, its contents cannot be changed. Operations that appear to modify a String actually produce another value.

CONCATENATION
-------------
For a small number of concatenations, normal + syntax is clear and often optimized by the compiler. In loops or complex construction, StringBuilder can make the intent and allocation behavior clearer.

EXAMPLE
-------
StringBuilder out = new StringBuilder();
for (String value : values) {
    out.append(value).append(',');
}
String result = out.toString();

COMMON MISTAKES
---------------
Using StringBuilder everywhere without need, comparing Strings with ==, and assuming immutability means a String can never be shared safely.

KEY TAKEAWAYS
-------------
String immutability is a useful safety property; use StringBuilder when repeated mutation is the natural construction pattern.
