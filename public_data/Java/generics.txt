GENERICS
========

Generics provide compile-time type safety for parameterized classes, interfaces and methods. They reduce casts and make APIs more expressive.

PARAMETERIZED TYPES
-------------------
List<String> communicates that the list is intended to contain String values. The compiler can then detect many incorrect uses before runtime.

WILDCARDS
---------
? extends T is useful when a structure is a producer of T values; ? super T is useful when it consumes T values. This producer/consumer view is often easier than memorizing a slogan.

EXAMPLE
-------
static <T> T first(List<T> values) {
    return values.get(0);
}

TYPE ERASURE
------------
Java generics are primarily a compile-time feature. Generic type information is subject to erasure in many runtime contexts, which explains several restrictions.

COMMON MISTAKES
---------------
Using raw types, overusing wildcards, and adding unchecked casts instead of fixing the API design.

KEY TAKEAWAYS
-------------
Generics improve API safety and readability. Prefer precise parameterized types and minimize unchecked operations.
