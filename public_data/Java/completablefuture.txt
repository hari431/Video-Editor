COMPLETABLEFUTURE
=================

CompletableFuture supports asynchronous composition and error handling without forcing every step into nested callbacks.

COMPOSITION
-----------
thenApply transforms a successful result, thenCompose chains an asynchronous operation, and exceptionally/handle can participate in failure handling.

EXAMPLE
-------
CompletableFuture<User> user = loadUser(id);
CompletableFuture<Account> account =
    user.thenCompose(this::loadAccount);

PRACTICAL DESIGN
----------------
Keep asynchronous boundaries meaningful. Avoid creating complicated graphs merely to appear asynchronous.

COMMON MISTAKES
---------------
Blocking immediately after starting async work, using the common pool without considering workload, and losing exception context.

KEY TAKEAWAYS
-------------
CompletableFuture is most valuable when independent or sequential asynchronous operations need to be composed clearly.
