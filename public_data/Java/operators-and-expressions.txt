OPERATORS AND EXPRESSIONS
=========================

Operators combine values into expressions. Java includes arithmetic, comparison, logical, assignment, bitwise, shift, conditional, and type-related operators.

CATEGORIES
----------
Arithmetic operators calculate numeric values. Relational operators compare values. Logical operators combine boolean expressions. The conditional operator can select between two expressions.

SHORT-CIRCUITING
----------------
The && and || operators may avoid evaluating the right-hand expression when the result is already known. This is useful for safe checks such as obj != null && obj.isValid().

EXAMPLE
-------
if (user != null && user.isActive()) {
    process(user);
}

PRECEDENCE
----------
Operator precedence determines grouping, but parentheses improve readability and reduce mistakes. Do not depend on readers remembering a long precedence table.

COMMON MISTAKES
---------------
Using == when value equality is intended for objects, mixing integer and floating-point arithmetic unexpectedly, and writing overly clever expressions are avoidable sources of bugs.

KEY TAKEAWAYS
-------------
Prefer clear expressions and parentheses when intent is not obvious; remember that == and object value equality are different concerns.
