GUIDEWIRE CLOUD API COMPOSITE REQUESTS
======================================

Composite requests allow multiple related API operations to be coordinated through a single client interaction where supported by the API framework.

WHY USEFUL
----------
Insurance transactions often require several related pieces of data. Composite capabilities can reduce round trips and make related changes easier to coordinate.

DESIGN CONSIDERATION
--------------------
A composite operation should be used when the operations are logically related and the API contract explicitly supports the combination.

RELIABILITY
-----------
Understand partial-failure semantics, validation, ordering and response structure before relying on a composite workflow.

COMMON MISTAKES
---------------
Assuming all APIs support arbitrary composition or treating composite requests as a substitute for a business-flow endpoint.

KEY TAKEAWAYS
-------------
Composite APIs can reduce integration chatter, but their semantics must be understood from the supported contract.
