GUIDEWIRE CLOUD API CRUD
========================

CRUD describes create, read, update and delete operations commonly used when working with REST resources.

REST MAPPING
------------
POST is commonly used to create or trigger operations, GET retrieves resources, PATCH partially updates resources, and DELETE removes resources when the resource contract permits it.

IMPORTANT CAVEAT
----------------
Not every insurance operation is ordinary CRUD. Binding, renewal, cancellation and other business actions often use purpose-specific operations because they represent business transitions.

EXAMPLE
-------
Updating an address may look like a resource update, while initiating a renewal is a business operation on a policy.

COMMON MISTAKES
---------------
Assuming every POST creates a database row or that every business action should be implemented as generic CRUD.

KEY TAKEAWAYS
-------------
CRUD is a useful API mental model, but insurance business transactions need domain-specific operations and state transitions.
