GUIDEWIRE CLOUD API AUTHENTICATION
==================================

API authentication establishes who or what is calling a service. Authorization then determines what that caller is allowed to do.

TWO CONCEPTS
------------
Authentication answers 'who are you?' Authorization answers 'what may you do?'. Keeping these concepts separate is essential.

GUIDEWIRE CLOUD AUTH FLOW
-------------------------
Guidewire Identity Provider (GW IdP) issues JWT bearer tokens via OAuth 2.0 client credentials:

POST https://api.guidewire.com/oauth2/token
  grant_type=client_credentials & client_id=xxx & client_secret=xxx & scope=pc.service

Response: {access_token: "eyJ...", expires_in: 3600, token_type: "Bearer"}
Subsequent Cloud API calls include `Authorization: Bearer eyJ...` and `GW-Release` header. The token's scopes (e.g., `pc.service`, `pc.admin`) enforce authorization.

PRACTICAL SECURITY
------------------
Credentials and tokens should be handled through approved secure mechanisms. Never place secrets in source code or public text files. Store client id/secret in a vault (e.g., environment variables on Render, not repo), request tokens server-side, and cache until `expires_in` minus 60s skew.

INTEGRATION DESIGN AND LEAST PRIVILEGE
--------------------------------------
Create separate service users per integration with minimal scopes: a rating integration needs `pc.service` read/quote but not `admin` delete. Rotate client secrets via the Guidewire Cloud Console; keep two active secrets briefly during rotation. Log `token hash prefix` rather than full token, and never log the bearer in access logs.

COMMON MISTAKES
---------------
Confusing authentication with authorization or treating possession of a token as permission for every operation. Also calling Cloud API without `GW-Release` header and receiving 401 when the tenant expects release pinning, or reusing an expired token without refresh and misdiagnosing as RBAC deny.

KEY TAKEAWAYS
-------------
Secure API integration requires both identity verification and permission control.
