POLICYCENTER ASSIGNMENT
=======================

Assignment determines which user or group should handle work such as activities, underwriting issues or other operational tasks.

ASSIGNMENT CONCEPTS
-------------------
Assignment can be based on rules, roles, groups, workload, geography, producer relationships or other configured criteria.

REFERENCE GROUNDING
-------------------
The supplied materials discuss user/group relationships, authority profiles and activity assignment concepts.

PRACTICAL DESIGN
----------------
A robust assignment strategy should be deterministic enough to explain why work went to a particular destination while allowing workload and organizational changes.

COMMON MISTAKES
---------------
Confusing assignment with authority. A user can be assigned work without necessarily having the authority to approve it.

KEY TAKEAWAYS
-------------
Assignment answers 'who should handle this work?' while authority answers 'what is this person allowed to do?'
