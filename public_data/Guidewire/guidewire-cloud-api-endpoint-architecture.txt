GUIDEWIRE CLOUD API ENDPOINT ARCHITECTURE
=========================================

REST endpoint architecture organizes APIs around resources and operations that represent business data and behavior.

RESOURCE MODEL
--------------
Resources such as policies, jobs, contacts, activities and forms can expose representations and operations. Some endpoints are generic while others are line-of-business-specific.

CURRENT DOCUMENTATION
---------------------
The current API reference exposes areas such as Policy Jobs, Policy Changes, Renewals, Reinstatements, Policy Forms, Policy Activities, Policy Notes and Policy Searches.

GENERATED LOB ENDPOINTS
-----------------------
Current Cloud API guidance distinguishes generic policy contents from line-of-business-specific structures, which may require generated endpoints.

COMMON MISTAKES
---------------
Assuming a generic endpoint contains every LOB-specific field or relying on endpoint shapes from an older release.

KEY TAKEAWAYS
-------------
Understand the resource hierarchy and distinguish generic policy data from line-of-business-specific API structures.
