GUIDEWIRE CLOUD API OVERVIEW
============================

Guidewire Cloud APIs expose insurance application capabilities through RESTful interfaces. Current PolicyCenter documentation separates business flows from lower-level resource operations.

BUSINESS FLOW VS RESOURCE
-------------------------
A business flow represents an insurance operation such as starting a renewal or completing a policy transaction. A resource endpoint can expose data or a more granular operation.

CURRENT DOCUMENTATION
---------------------
Current PolicyCenter Cloud API documentation describes job types including submissions, renewals, audits, policy changes, cancellations, reinstatements and rewrites.

RESOURCE MODEL EXAMPLE
----------------------
PolicyCenter Cloud API exposes the same Job concept as the desktop: `POST /job/v1/jobs` creates a Job, `GET /policy/v1/periods/{id}` reads a Period, `POST /job/v1/jobs/{jobId}/quote` runs rating. Business flows (Submission, PolicyChange) orchestrate multiple resource calls; a single resource call is not the whole flow.

RELEASE-SPECIFIC EXAMPLE
------------------------
Jasper (2023.06) vs Innsbruck (2024.02) differ in required fields for `POST /job/v1/jobs`:

Jasper  {jobType: "Submission", productCode: "PersonalAuto", effectiveDate: "2026-03-15"}
Innsbruck {jobType: "Submission", productCode: "PersonalAuto", effectiveDate: "2026-03-15", baseState: "CA"}

The productCode enumeration and mandatory address fields expand between releases. Always fetch `/openapi.json` for your tenant's release.

PRACTICAL APPROACH
------------------
Start with the business outcome, identify the job/resource involved, then follow the current API reference for the exact endpoint and request schema. Validate the request against the OpenAPI schema for your release before testing against the tenant.

COMMON MISTAKES
---------------
Treating an API endpoint as the whole business process or copying an endpoint from an old release without checking the current documentation. Also calling `quote` before required coverages are patched, which returns 422 instead of a price.

KEY TAKEAWAYS
-------------
Learn Cloud API from the business flow first, then the resource model and exact release-specific API reference.
